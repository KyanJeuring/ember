Syntax hierarchy

Orange — language identityImports, declarations, modifiers, directives, built-ins and special syntax.
Purple — program flowConditionals, loops, returns, coroutines and keyword operators.
Blue — callable symbolsFunctions, methods and function calls.
Cyan — typesTypes, classes, interfaces, structs and type parameters.
Green — stringsStrings, paths and successful/additive states.
Yellow — values and metadataNumbers, constants, attributes, annotations and warnings.
Red — exceptional statesErrors, exceptions and destructive actions.
Neutral — ordinary codeVariables use fg0; members, modules and punctuation lean on fg1.
